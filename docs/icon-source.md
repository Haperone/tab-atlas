# Tab Atlas icon

The product icon is Freeicon's two-color **Bookmarks** icon selected by the project owner:
https://freeicon.com/ru/free-icons/bookmarks/two-color

Original public image: https://storage.freeicon.com/free-icon-icon-OAtnnclXJiff

`extension/icons/icon512.png` is the transparent 512-pixel source image converted
losslessly from the provider's WebP. The 16, 32, 48 and 128-pixel PNGs are Lanczos
resizes of that image; the original colors and transparency are preserved.
`docs/icons/icon32.png` is an identical copy for the public site's favicon.

Use `extension/icons/icon128.png` for the Chrome Web Store listing icon.
The already published 1.2.0 ZIP retains its original assets; this change belongs
to the next release.
