# Нативная приёмка Time machine

> Устаревший checklist для browser-tab prototype. Не выполнять его как приёмку
> Atlas snapshot history. Актуальная таблица —
> [atlas-history-native-checklist.md](atlas-history-native-checklist.md).

Эти проверки ещё не выполнены. Стенд с настоящей IndexedDB и Worker использует
синтетические Chrome APIs и не заменяет проверку установленного расширения.
Версия исходников остаётся 1.2.0; опубликованный ZIP не содержит новую функцию.

Использовать отдельный тестовый профиль Chrome и unpacked-расширение из
`E:\Projects\tab-out-new\extension`. Проверять минимум текущий Chrome; совместимость
с заявленным минимумом Chrome 109 также остаётся отдельной проверкой.
Для страниц можно использовать локальные `/docs/privacy-policy.html?tm=1`,
`?tm=2` и варианты с fragment на сервере `node tools/serve.mjs 8232`.
Не собирать реальные URL пользователя в отчёт — достаточно результата и счётчиков.

| Проверка | Действия и ожидаемый результат | Результат |
| --- | --- | --- |
| Opt-in | Новая установка/обновление: запись выключена. Customize → Time machine → Enable local history создаёт начальный момент обычных окон. | Не проверено |
| События | Создать/закрыть страницы, изменить адрес, перенести вкладку между двумя окнами, закрепить, создать/переименовать/перекрасить/свернуть группу. Перемотка показывает верные метаданные и порядок. | Не проверено |
| Исключения | Открыть внутреннюю страницу и private window. Они отсутствуют в истории; действие из private-контекста не выполняется. | Не проверено |
| Закрытый dashboard | Закрыть Tab Atlas, изменить вкладки, открыть dashboard снова. Изменения наблюдаются в фоне. | Не проверено |
| Жизненный цикл worker | Остановить service worker через chrome://extensions/инструменты разработчика; совершить событие. Журнал и ключи сохраняются, пропущенное отмечено сверкой/разрывом. | Не проверено |
| Рестарт Chrome/обновление | Перезапустить Chrome и reload расширения. Старые моменты доступны; новый browser session не переиспользует старые ключи. После перезапуска старый Undo недоступен. | Не проверено |
| Restore | Существующий точный URL переключается/пропускается. Query/fragment различаются. Выбранные вкладки/домен/момент создаются в новых обычных окнах с порядком, pin и группами. Существующие окна не перемещаются. | Не проверено |
| Stop/ошибка/обрыв | Прервать массовое открытие; остановить worker во время операции. Нет автоматического продолжения. Известные созданные вкладки доступны для безопасного Undo, неизвестные остаются. | Не проверено |
| Undo | Одну созданную вкладку перенести, другую перенаправить, третью перепинить; добавить чужую вкладку в созданное окно. Undo закрывает только неизменённые принадлежащие операции вкладки. Проверить редирект при первой загрузке и повтор Undo. | Не проверено |
| Feedback | Зелёная плашка снизу, полоса таймера, hover/focus → Undo со стрелкой; звук save/undo и настройка Sound off. После исчезновения плашки Undo остаётся в меню. | Не проверено |
| Доступность | Клавиатурой пройти меню, шкалу, поиск, выбор, подтверждения и Undo; Escape возвращает фокус. Реальный browser zoom 200%, Windows forced colors и системный reduced motion; проверить экранный диктор. | Не проверено |
| Регрессии | Toolbar popup/ПКМ, drag с wheel/autoscroll, saved/folders/archive/workspaces, импорт/экспорт schema 1 и storage warning продолжают работать. Backup не включает историю. | Не проверено |
| Потеря базы | В тестовом профиле удалить только IndexedDB Time machine: сохранённые коллекции остаются; при включённой записи создаётся новый baseline. | Не проверено |

В browser harness отдельно пройдены 320 px, 16 тем, проектный reduced motion,
модальные состояния, ошибки, native IDB rollback/blocked/schema и прерывание
native Worker. Их результаты находятся в `time-machine-*.json`.
