# Atlas Time machine: приёмка установленного расширения

Актуальная модель: [ТЗ](time-machine-spec.md). Это список **непроверенных** нативных
границ, не отчёт об успехе. Проверять unpacked `E:\Projects\tab-out-new\extension`
в отдельном профиле Chrome с синтетическими папками и ссылками. В рабочем профиле
не выполнять полный restore/Clear ради проверки. Не собирать пользовательские URL
в отчёт. Версия/permissions/release ZIP не меняются.

После изменения background кода перезагрузить расширение в `chrome://extensions`,
затем открыть обычную вкладку через **Open Tab Atlas** из toolbar popup.
Обновление одной dashboard вкладки не заменяет работающий background worker.

Последняя проверка доступности браузеров: inventory показывает только Codex
In-app Browser и MCP Apps, подключённого Chrome сейчас нет. Ранее открытая
пользователем extension/index.html была видна, но getTab отклонялся browser
security policy, допускающей только http/https. Это два ограничения одной
непроверенной нативной границы; повторное открытие вкладки их не устраняет.
Автоматизированный доступ к установленной странице/worker не проверен, запрет
не обходится. Таблицу заполнять только по реальным результатам Chrome.
Первый checkpoint: Customize → Time machine показывает папки и сохранённые ссылки,
а не группы открытых browser tabs. До ручного ответа результат неизвестен.

| Граница | Проверка и ожидаемый результат | Статус |
| --- | --- | --- |
| Автоматическая запись / состав | С первого запуска запись работает без Enable. Папки, активные ссылки и порядок есть в истории, архив отсутствует. Off/pause сохраняется после restart. Обычное открытие/закрытие вкладки и изменения только архива не создают момент. | Не проверено |
| Общий владелец | Два dashboard одновременно rename/move/save, затем popup и ПКМ. Все подтверждённые правки остаются; момент не смешивает части удаления/импорта. | Не проверено |
| Закрытый dashboard | Закрыть dashboard, сохранить через popup/ПКМ, снова открыть Time machine. Изменения коллекций записаны без dashboard. | Частично: 2026-10-06 пользователь подтвердил обновление времени последнего слепка после сохранения с закрытым dashboard. Конкретный путь popup/ПКМ не указан; оба пути и состав записанного состояния отдельно не подтверждены. |
| Массовая запись | Save selection / group → folder / Apply Sweep дают один согласованный момент. При отказе local commit вкладки остаются открытыми, новой пустой папки нет. | Не проверено |
| Restore папки | С тем же именем и с переименованным stable id предложены Replace/Add missing/Copy. Если совпадений несколько, выбран конкретный target. Cancel ничего не меняет, lock запрещает replacement. | Не проверено |
| Выборочные ссылки | Восстановить одну ссылку в прежнюю папку, включая возвращение отсутствующей папки только с выбранными ссылками. Совпадение имени разрешается явно; соседи не добавляются. Исторические ссылки без папки остаются в inbox. | Не проверено |
| Полный restore | В тестовом профиле восстановить момент; активные folders/deferred/order соответствуют ему. Исторические активные id реактивируются из текущего архива без дубликатов; прочий архив сохраняется. Настройки/workspace/browser tabs не меняются. | Не проверено |
| Open link | Открыть историческую ссылку отдельно; новое browser window не создаётся. Точный существующий URL активируется только в текущем normal window. File access / unsupported address объясняются, исходная ссылка остаётся в слепке. | Не проверено |
| Durable Undo | Дождаться исчезновения плашки; перезапустить worker и затем Chrome. Undo/Before доступны. Undo возвращает Before; Before Undo позволяет вернуть восстановленное состояние. | Не проверено |
| Undo после правок | После restore добавить/переименовать ссылку. Undo требует подтверждения. Cancel сохраняет правки; подтверждение защищает их в Before Undo. | Не проверено |
| Stale Undo | Начать dashboard save/delete, восстановить Atlas до показа старой плашки. Её Undo не меняет новый Atlas даже при совпавших id; актуальное долговечное Undo работает. | Не проверено |
| Остановка worker | Остановить worker до local commit и после него, до/после journal target receipt. Пробудить новым действием: без receipt нет replay target; с receipt finish идемпотентен. Повтор потерянного ответа не делает второй restore/Undo. | Не проверено |
| Архив / миграция | В слепках нет архивных строк и переключателя. Старые моменты после обновления сохраняют даты и активные ссылки; ранее защищённый Undo работает. Реактивация возвращает активный id без дубликата; Undo точно возвращает его предыдущее архивное состояние. | Не проверено |
| Сравнение | Полностью присутствующие группы (включая Saved for later) и существующие пустые папки скрыты. Полностью отсутствующие папки красные; в смешанных группах отсутствующие ссылки красные и первыми, существующие/перенесённые зелёные и ниже. Поиск и пагинация не возвращают скрытые группы. Удалённые пустые папки доступны. Полное восстановление включает скрытые группы. Постоянных подписей нет; детали доступны при наведении/для чтения с экрана. Новые текущие изменения обновляют сравнение без сброса момента. | Не проверено |
| Ошибки | History quota/blocked/corruption не ломают current collections или ordinary save. Restore без защиты запрещён. Retry/explicit confirmed Clear доступны; никакого автоматического wipe. | Не проверено |
| Плашка / звук | Bottom-center success, timer, hover и keyboard focus → Undo/back icon. Save и Undo звучат при Sound on; off/reduced motion соблюдены. | Не проверено |
| UI | Off/empty/loading/pause/error/quota, 16 тем, 320 px, 200% zoom, forced colors, Escape/focus/keyboard и большие коллекции не оставляют unreachable controls. Панель восстановления видна при прокрутке, показывает дату/объём выбора и Reviewing/Restoring/Undoing; при отказе объяснение с Retry появляется в видимой области. Cancel сохраняет выбор и возвращает фокус к кнопке. | Не проверено |

Native localhost IDB/UI fixtures в Chrome уже имеют отдельные сохранённые отчёты,
но они используют synthetic Chrome APIs и не закрывают эту таблицу. Производительность
и near-budget acceptance описаны отдельно в [progress](atlas-history-progress.md).
